YouTube Full Captions

This extension changes the way auto-generated subtitles are displayed in YouTube. Instead of appearing word by word, the captions appear line by line, making it easier to read.

To use it, install the extension and just click on its icon when you view a video. To deactivate the captions and return to the default state, click on the icon again, which reloads the YouTube page.

Once activated, you can change the appearance of the captions by right-clicking on the extension's icon, and choosing "Caption Settings".
